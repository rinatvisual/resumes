# Резюме по шаблону

Сайт переводит резюме (.docx, .txt или вставленный текст) в Word-файл единого оформления.
Пропущенные блоки отмечаются красным — и на сайте, и в готовом Word-файле.

Всё работает в браузере: файлы никуда не отправляются, сервер не нужен.

## Файлы
- `index.html` — страница сайта
- `style.css` — оформление
- `app.js` — интерфейс (загрузка, предпросмотр, скачивание)
- `resume.js` — разбор текста по блокам и сборка Word
- `ai.js` — обработка через Claude API: чистка от лишнего и раскладка по блокам (инструкция для Claude — функция `systemPrompt`)
- `template.js` — шаблон Word (фон, поля, шрифты), встроенный в код
- `template.docx` — тот же шаблон отдельным файлом (для справки)
- `lib/jszip.min.js` — библиотека для работы с .docx

## Как поменять шаблон
Оформление страницы (фон, поля, колонтитулы) берётся из `template.js`.
Шрифт, размер и жирность текста задаются в `resume.js` (функция `r`).

## Claude
Кнопка «Настройки Claude» → вставить ключ API (console.anthropic.com → API Keys).
Модель по умолчанию — Claude Haiku (экономно). Поле «Мои правила редактуры» — свои указания, которые добавляются к основной инструкции при каждом запросе.
Основная инструкция кэшируется на стороне Claude, повторные запросы за неё платят меньше.
Ключ хранится только в браузере (localStorage) и в репозиторий не попадает.
Claude возвращает данные по блокам, сайт превращает их в текст стандартного вида — его можно поправить руками перед скачиванием.

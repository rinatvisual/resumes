# Резюме по шаблону

Сайт переводит резюме кандидатов (.docx, .txt или вставленный текст) в Word-файл единого оформления по эталону.
Пропущенные блоки отмечаются красным — и на сайте, и в готовом Word.

Адрес: https://rinatvisual.github.io/resumes/

Сайт работает в браузере, сервера нет. Резюме уходят только в Claude API (если он подключён); контакты кандидата вырезаются ещё до отправки.

## Как пользоваться
1. «Настройки Claude» → вставить ключ API (console.anthropic.com → API Keys) → «Сохранить».
2. Перетащить резюме (.docx / .txt, можно несколько) или нажать «Вставить текст вручную».
3. Проверить результат справа:
   - красное — блоки, которых нет в резюме;
   - красная плашка — образование, найденное в «О себе» (перенести вручную);
   - жёлтое — замечания Claude (противоречия, расширенные обязанности / «О себе»).
4. При необходимости поправить текст слева — результат обновится сразу.
5. «Скачать Word» или «Скачать все (.zip)».

## Что делает обработка
**Сайт (бесплатно, без Claude):**
- читает .docx (вместе с фото кандидата) и .txt (UTF-8 и Windows-1251);
- до отправки в Claude убирает телефоны, почту, ссылки, ники, подсказки конструкторов, памятку шаблона;
- раскладывает текст по блокам, считает срок работы включительно («Январь 2022 - апрель 2022 (4 месяца)»);
- сортирует места работы от новых к старым;
- оформляет обязанности: «- С большой буквы;», последняя — с точкой;
- переносит фото в левую колонку шапки;
- подсвечивает красным пустые блоки, достижения, форму обучения, город;
- убирает «Доп. образование», если курсов нет.

**Claude (основной запрос):** чистит от лишнего, исправляет ошибки, раскладывает по блокам, считает возраст по дате рождения, оставляет город проживания, названия организаций не меняет.

**Claude (доработка, только при необходимости):** если обязанностей 2–5 — доводит до 6 детализацией; расписывает обязанности из 3 слов и короче; доводит «О себе» до 6 предложений одним абзацем.

## Настройки Claude
- **Модель** — по умолчанию Haiku (дешевле); Sonnet / Opus точнее.
- **Мои правила редактуры** — свои указания к каждому запросу; «Вернуть стандартные правила» восстанавливает исходные.
- **Кэш инструкции** — 1 час или 5 минут. Инструкция и правила кэшируются, повторные запросы за них платят в 10 раз меньше.
- Ключ хранится только в этом браузере (localStorage) и в репозиторий не попадает.

Строка «Токены» под жёлтым блоком показывает расход: обычные, из кэша, записано в кэш, выход, была ли доработка.

## Файлы
- `index.html` — страница сайта
- `style.css` — оформление сайта
- `app.js` — интерфейс: загрузка, предпросмотр, настройки, скачивание
- `resume.js` — разбор текста по блокам, извлечение фото, сборка Word
- `ai.js` — работа с Claude API: очистка текста, основная инструкция (`systemPrompt`), проверка и доработка (`checkRules`, `repair`)
- `template.js` — шаблон Word (фон, поля, колонтитулы), встроенный в код
- `template.docx` — тот же шаблон отдельным файлом (для справки)
- `lib/jszip.min.js` — библиотека для работы с .docx

## Номер версии
В `index.html` у всех подключаемых файлов стоит `?v=НОМЕР` (и он же показан в заголовке сайта).
После любого изменения файлов номер нужно поменять во всех местах сразу — тогда браузеры гарантированно возьмут свежие файлы, а не старые из кэша.

## Как поменять оформление
Фон, поля и колонтитулы — в `template.js`. Шрифт, размер, жирность и красная подсветка — в `resume.js` (функции `r` и `missRun`).
